## 2026-11-17（周二）

**做了什么**

- **整理了技能工坊 Ability Studio 的开发成果**：已经可以从模块库拖出节点，连接攻击范围、目标和效果，保存成技能资产，再到测试场景里试玩。下面汇总截至本次发布已完成的功能，包含此前开发积累；今天将这些功能一起打包到 0.2.1。
- **攻击基础节点**：提供普通攻击和特殊攻击两个输出，可以分别连接完整的攻击节点。一把武器可以配置两种攻击，分别设置伤害、冷却和最大施法距离；测试场景里用左键 / 右键触发，两边冷却独立。
- **一体攻击节点**：把原来分开的释放设置合并进攻击范围节点，直接选择“瞬发”或“蓄力”，减少搭建时的连线。切换模式会保留隐藏参数和已连接的效果。旧技能不会自动改写，提供可撤销的转换入口；不兼容的旧分支保留原结构。
- **蓄力功能**：圆形支持半径增长，扇形支持距离增长，长方形支持长度增长；分别配置初始范围、蓄满范围和蓄满时间。按住蓄力，松手按当前比例释放，蓄满不会自动释放；取消不消耗冷却。投射物支持蓄力后释放，但弹道参数不随蓄力变化。蓄力期间另一个攻击键不会补放或排队。
- **圆形范围节点**：在指定圆心对范围内目标进行一次攻击，可配置半径。默认圆心跟随鼠标对应的技能终点，超过最大施法距离时限制在边界内；也可以连接位置输入。当前圆形是瞬时判定，还不是持续留在地上的区域。
- **扇形范围节点**：配置距离和角度，朝瞄准方向攻击范围内的目标，适合挥砍类攻击；预览和实际命中使用同一套范围计算。
- **长方形范围节点**：配置长度、宽度和前端区域深度；可以把普通区域与前端区域分别接到不同效果，例如普通区域 100% 伤害、前端 150% 伤害并眩晕。普通区域和前端区域的目标互斥，跨分界的目标归前端；“命中目标”输出仍包含全部命中目标。
- **投射物节点**：配置速度、射程和大小，飞行途中检查碰撞并把命中目标交给效果节点。使用连续碰撞检测，减少高速飞行漏判；已发射的投射物保留释放时的参数，修改数值从下一次释放生效。
- **命中响应节点**：做了“穿透”“连锁”“返回”。穿透让投射物命中后继续飞；连锁寻找附近未命中的目标；返回让投射物飞回施法者当前的位置，回程可以再次命中。同一投射物可组合这些响应，按穿透 → 连锁 → 返回处理；节点只影响连接到它的投射物。
- **倍率和状态效果节点**：“倍率”按所属攻击的基础伤害百分比结算；“流血”配置每秒伤害和持续时间；“减速”配置百分比和持续时间；“眩晕”配置持续时间。效果连接到对应目标后才生效；流血、减速、眩晕的重复施加按当前刷新规则处理，不会简单无限叠加。
- **拉拽和击退节点**：拉拽可以设置目的地、停止距离和持续时间，用来把目标拉近或聚拢；击退把目标向外推开。已经支持把拉拽完成后的目标接到眩晕等后续效果，做出“先拉过来，再生效”的组合。
- **位置和目标连接**：技能终点受最大施法距离限制，可以供圆心、拉拽目的地等位置输入共用。攻击的命中目标连接到需要的效果，支持同类节点多实例、独立参数和手动连接；没有连接目标的效果不执行。删除节点会清理相关连接，并支持撤销。
- **画板和模块库**：完成中文分类、节点名称、参数和帮助提示；支持搜索模块、拖入画板、移动节点、连线 / 断线、删除、撤销 / 重做和保存布局。调整了点阵背景、节点参数显示和目标接口提示，让搭建、检查连接和调数值更直观。
- **测试场景和共用运行时**：从画板进入独立 Playground Scene，可移动角色、瞄准释放、添加 / 重置木桩，并查看范围预览、伤害、状态倒计时和冷却；移动木桩可以验证减速效果。首次使用会创建缺少的测试资源，示例不会覆盖已有技能。测试场景与游戏接入使用同一套技能执行器和资产，主项目仍需实现自己的输入与目标适配。
