## 2026-11-15 · T005d1 · 修卡死：怪物不再推玩家

**问题**（用户试玩发现）：被怪物贴近以后，角色会被卡住，WASD 都动不了。Claude 复现：
- 1 只怪贴上来，玩家不按键也被推着走（3 秒推了 1.35）。
- 3 只怪三面围住，会把玩家顶到车底墙上；按"下"反而被往上推。
- 原因：Kinematic 的怪物只和障碍物留 0.002 的空隙，比物理接触的 contact offset（0.01）小，物理引擎就把 Dynamic 的玩家挤开了。

**做了什么**（Codex 编写，Claude 审查，修了 1 轮）
- `Monster` 新增 `LimitDynamicContact`：怪物每次移动前，都检查自己离 Dynamic 刚体（玩家）够不够远，要保留"双方 contact offset + 原空隙"的距离，不会再往玩家那边靠近。玩家已经贴进这段间隙时，只允许怪物往远离玩家的方向走。直走、滑动、击退、避让都经过这个检查。
- **补丁 1**：第一版里，玩家主动顶住怪物时还是会被慢慢往后推（每秒 0.4）。原因是"往哪边算远离"的判断方向算反了。

**审查 / 实测**
- 编译 0 错误 0 警告；场景生成 3 次，131 个引用都不为空；93 个测试全部通过；Console 没有报错。
- Play：
  - 1 只怪贴着、玩家不按键 3 秒：不动。玩家往右顶住怪 3 秒：只移动了 0.014。
  - 3 只怪三面围住：玩家不动；按"下"、"右"顶住时也只移动了 0.014；按"上"能正常走开。
  - 回归：车底、车顶迎面相撞的两只都能错开并到达两头；自然跑 25 秒，5 只怪都到了自己那一头。
