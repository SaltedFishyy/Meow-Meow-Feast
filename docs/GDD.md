# Meow Meow Feast（MMF）— 游戏设计文档

> 状态：**原型设计 v0.1**　·　最后更新：2026-11-15　·　维护：Claude
> 标记说明：**【定】** 已确认　**【暂定】** Claude 先定的初稿，等试玩或用户调整　**【待定】** 需要用户拍板

---

## 1. 一句话

一款多人合作的 Roguelite 餐车经营 × 动作塔防游戏：队友有人在餐车里做菜，有人在车外打怪收集食材，大家一起守住这辆在危险世界里营业的移动据点。【定】

## 2. 核心卖点（来自企划书）

1. **战斗与经营双线并行**：车内做菜、车外打怪同时发生，互相影响。
2. **动态岗位**：没有固定职业，谁都能进车做菜、出车打怪；关键是判断什么时候离开自己的岗位去支援。
3. **料理是操作，不是进度条**：切、煮、煎都需要玩家动手，成长会改变操作方式。
4. **Roguelite 构筑**：手动料理流、自动化流、混合流，每局组出不同的餐车团队。

**设计北极星**：经营餐车本身就是合作战斗，而不是战斗之外的休息环节。

## 3. 世界观（简）

奇幻动物世界被诅咒侵蚀，动物们被封住了记忆与情感，变成怪物。玩家是一支餐车队，开着餐车四处营业：用"净化料理"唤醒动物的记忆、恢复它们的灵魂。顾客也是动物，吃到料理会想起什么、露出笑容。【暂定】

## 4. 原型目标与范围

**原型只回答一个问题：一边做菜、一边打怪、一边守车，好不好玩？**

| 原型包含 | 原型不包含（之后再做） |
|---|---|
| 1 个固定镜头的关卡，餐车在中间 | 网络联机（以后要做，代码结构要为它留余地）【定】 |
| **1 名玩家（单人）**【定】 | Roguelite 构筑、局外成长 |
| 2 种食材、3 道菜、3 种操作站 | 自动化设备 |
| 1–2 种怪物，波次进攻 | 多关卡、地图、行车移动 |
| 顾客订单 + 耐心值 | 正式美术、动画、音乐 |
| 餐车血量、胜负判定、分数 | 剧情、存档、设置菜单 |

## 5. 原型详细玩法

### 5.1 一局的流程【暂定】

1. **开店**（0:00）：餐车停在场地中央，玩家出生在车内。第一位顾客 3 秒后到。
2. **营业 + 防守**（0:00–4:00）：顾客不断来下单；从 0:20 开始，怪物从场地边缘一波波涌向餐车。
3. **结束**：
   - 撑满 **4 分钟** 且餐车没被打爆 → **胜利**，按金币结算星级。
   - 餐车血量归零 → **失败**。

### 5.2 镜头与场地

- **2D 俯视、固定镜头，类似《胡闹厨房》（Overcooked）**【定】
- 整个场地一屏放下。【暂定】
- 餐车在正中央，**车顶透明**，能直接看到车内布局。车有一个**车门**（玩家进出）和一个**出餐窗口**（面向顾客排队的一侧）。
- 车外：左右两侧是野外，有**蘑菇丛**（采集点）；怪物从屏幕左、右、上三个边缘刷出。
- 顾客从下方走来，在出餐窗口前排队（最多 3 位）。

```
        ↓ 怪物            ↓ 怪物
  [蘑菇丛]   ┌──────── 餐车 ────────┐   [蘑菇丛]
 → 怪物      │ 食材箱 砧板  锅  煎锅 │      怪物 ←
             │      (车内空间)        │
             └──门────────出餐窗口───┘
                          🐱🐶🐰 顾客排队
```

### 5.3 玩家【暂定】

| 项目 | 原型设定 |
|---|---|
| 移动 | 8 方向，速度 5 单位/秒；车内外一样 |
| 手持 | 一次只能拿 **1 样东西**（食材、半成品、成品） |
| 互动 | 靠近物体按"互动键"：拿起 / 放下 / 放入站点 / 取出 / 出餐 |
| 动作键 | 在操作站旁 = 执行料理操作；在其他地方 = **挥爪攻击**（近战，前方扇形，伤害 1，冷却 0.4 秒） |
| 血量 | 3 点。归零后**倒地**，5 秒后在车内复活，手上的东西掉在原地 |
| 岗位 | **没有固定职业**：谁走进车谁就是厨师，谁走出去谁就是猎人 |

**角色名**：`Player`。原型用占位图形，之后换成正式图片。【定】

**操作方式**
- **WASD 移动 + 鼠标**；之后可以再加其他输入方式（手柄等）。【定】
- 鼠标具体负责什么、互动键和动作键是哪个：【待定】

### 5.4 食材【暂定】

| 食材 | 来源 | 说明 |
|---|---|---|
| 🍄 **蘑菇** | 车外蘑菇丛：站在旁边按住动作键 1 秒采集；每丛采后 8 秒再长 | 安全但要离车 |
| 🥩 **怪肉** | 击败怪物掉落，掉在地上 10 秒后消失 | 打怪的奖励 |
| （车内**食材箱**） | 开局各有 2 份蘑菇、2 份怪肉，**拿完就没了** | 让第一分钟能开张 |

### 5.5 料理站（操作玩法）【暂定】

每个站点一次处理一份。都是"动手"的，不是干等。

| 站点 | 输入 → 输出 | 操作 | 失败情况 |
|---|---|---|---|
| **砧板** | 怪肉 → 肉块 | **连打**动作键 6 次（每次有剁的反馈） | 无；离开就暂停，回来继续 |
| **锅（煮）** | 放进 2 样东西 → 汤 | 放好后自动煮 6 秒；期间**每 2 秒按一次动作键搅拌**，漏一次多 2 秒 | 煮好后 8 秒没取出 → **煮糊**（变黑暗料理，只能扔进垃圾桶） |
| **煎锅（烤）** | 肉块 → 烤肉 | 指针在条上来回摆动，按动作键停在**绿区**完成；黄区也算完成但品质"普通"；红区失败要重来 | 连续 3 次红区 → 肉焦了 |
| **出餐窗口** | 成品 → 交给排在最前的、点了这道菜的顾客 | 拿着成品按互动键 | 没人点这道 → 不能交 |
| **垃圾桶** | 扔掉手上的东西 | 互动键 | — |

### 5.6 菜谱【暂定】

| 料理 | 做法 | 售价 | 净化值 |
|---|---|---|---|
| **烤肉串** | 怪肉 → 砧板 → 煎锅 | 10 金币（绿区完美 +5） | 1 |
| **蘑菇汤** | 蘑菇 + 蘑菇 → 锅 | 8 金币 | 1 |
| **蘑菇炖肉** | 肉块 + 蘑菇 → 锅 | 15 金币 | 2 |

### 5.7 顾客与订单【暂定】

- 顾客每 **12 秒**来一位（后期 9 秒），最多同时排 3 位，多出来的不来。
- 每位顾客点 1 道菜，头上显示菜的图标和**耐心条**（30 秒）。
- 按时上菜 → 得金币 + 小费（耐心剩得越多小费越多，最多 +50%）。
- 耐心耗尽 → 顾客生气离开，不扣钱，但**餐车受到 5 点伤害**（顾客的"诅咒"被激发）。【暂定，用来把经营失误和守车压力连起来】

### 5.8 怪物与防守【暂定】

| 怪物 | 血量 | 速度 | 行为 | 掉落 |
|---|---|---|---|---|
| **咒化团子**（小怪） | 2 | 慢（1.5） | 直线走向餐车，贴住后每秒啃 2 点车血 | 怪肉 ×1（60%） |
| **咒化野猪**（中怪，2:00 后出现） | 5 | 快（3），冲撞 | 朝车冲撞一次 10 点伤害，然后在原地晕 2 秒再冲 | 怪肉 ×2 |

- **波次**：0:20 起每 20 秒一波；每波小怪数 = 2 + 波数/2（向下取整）；2:00 后每波加 1 只野猪。
- 怪物会攻击挡路的玩家（1 点伤害），但目标始终是餐车。
- **餐车血量 100**，原型里不能修理。【待定：要不要加"修理"作为厨师离岗的理由？】

### 5.9 胜负与结算【暂定】

- 胜利：撑满 4 分钟。按金币给星：⭐ 60 / ⭐⭐ 120 / ⭐⭐⭐ 180。
- 失败：餐车血量 0。
- 结算画面显示：金币、上菜数、错过的订单数、击败怪物数、餐车剩余血量；按互动键重开。

### 5.10 界面（HUD）【暂定】

- 顶部中间：剩余时间、金币。
- 顶部左侧：餐车血条。
- 每个玩家头顶：手上拿的东西图标、血量点。
- 顾客头顶：订单图标 + 耐心条。
- 站点上方：进度条 / 摆动条 / 搅拌提示。

### 5.11 想通过试玩回答的问题

1. 双人时，会不会自然出现"一个人在里面、一个人在外面"，并且时不时互相支援？
2. 单人时，里外来回跑是有趣的忙碌，还是纯粹的折磨？
3. 料理操作（连打、搅拌、摆动条）是否有手感，还是只是麻烦？
4. 守车压力和做菜压力哪个更大？两者有没有真正互相影响？

## 6. 原型之后（方向，未细化）

- **Roguelite 构筑**：每波之间三选一升级（例："砧板连打次数 -2"、"锅自动搅拌"、"挥爪变成范围攻击"）。区分手动 / 自动化 / 混合流派。
- **自动化设备**：自动切菜机、保温台、炮台（用料理当弹药？）。
- **行车与地图**：餐车在节点地图上移动，每站一个关卡。
- **联机**：原型验证好玩之后再选方案。
- **净化系统**：顾客吃到料理后的记忆演出，和世界观连起来。
