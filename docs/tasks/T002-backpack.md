# T002 — 背包、选格、自动捡起、Q 丢弃、掉落物

> 给 Codex：先读 `AGENTS.md`，再读本说明书，再读下面列出的 GDD 章节。T001 已完成，代码在 `Assets/_MMF/`，先看懂现有结构再动手。

## 目标
Player 有一个 5 格背包。场景里放着几个测试用掉落物（怪肉、蘑菇），Player 走过去会自动捡进背包，同类东西会叠起来。可以用数字键或滚轮选格，按 Q 把选中格里的东西丢 1 个在脚下。屏幕下方显示背包栏，Player 头顶显示当前选中的物品。

## 相关设计
- `docs/GDD.md` §5.3 里"背包""掉落物""显示""测试物品"这几段（以 GDD 为准）。
- GDD 里标 🟡【暂定】的数值以后会改，**全部要做成 Inspector 可调参数**（或放在 ScriptableObject 里），不能写死。

## 规则（摘自 GDD，必须完全照做）

| 规则 | 值 |
|---|---|
| 背包格数 | 5 🟡 |
| 每格最多叠放 | 3 个同类物品 🟡 |
| 能装的东西 | 任何物品（本任务只有"怪肉""蘑菇"两种测试物品） |
| 捡起时放哪 | **先叠到已有的、没叠满的同类格子**；没有就放进**第一个空格** |
| 背包放不下 | 不捡，东西留在地上 |
| 自动捡起距离 | 半个身位 ≈ **0.5 单位**（Player 是 1×1） 🟡 |
| 选格 | 数字键 **1–5** 直接选；鼠标滚轮**往下 = 下一格，往上 = 上一格，不循环**（第 5 格往下滚还是第 5 格，第 1 格往上滚还是第 1 格）；开局选中第 1 格 |
| 手上拿的 | 就是**当前选中的那一格**，没有单独的"手" |
| Q 键 | 把选中格里的物品**丢 1 个在 Player 脚下**；格子空就什么都不做 |
| 丢掉后多久能再捡 | **2 秒**内不会被自动捡起 🟡 |
| 地上的东西多久消失 | **60 秒** 🟡（Q 丢的东西从丢下那一刻重新计时） |
| 背包栏 | 屏幕**下方正中间一排 5 格**；选中格高亮；格子里显示物品颜色块 + 名字；数量大于 1 时显示数量（如 `x2`）；空格显示空 |
| 头顶图标 | Player 头顶显示**选中格**物品的小色块 🟡；选中格是空的就不显示 |

## 要做的事
1. **物品数据**：ScriptableObject `ItemDefinition`（`MMF.Data`）：id、显示名（中文）、占位颜色。建两个资源放在 `Assets/_MMF/Data/Items/`：
   - `MonsterMeat`：显示名"怪肉"，红色系
   - `Mushroom`：显示名"蘑菇"，浅褐 / 米色系
2. **背包逻辑**：把规则写在一个**不依赖 MonoBehaviour 的纯 C# 类**里（例如 `BackpackModel`），方便以后联机和写测试；再用一个组件（例如 `PlayerBackpack`）挂在 Player 上，持有它并对外发事件（内容变化、选中格变化）。格数、叠放上限都是可调参数。
3. **输入**：在 `MMFControls.inputactions` 的 `Gameplay` 里**新增**：
   - `SelectSlot1` … `SelectSlot5`（键盘 1–5，主键盘数字键）
   - `ScrollSlot`（鼠标滚轮 Y 轴）：只看方向，一次滚动只移动 1 格
   - `Drop`（键盘 Q）
   - 输入仍然只在 `PlayerInputReader`（或同样职责的读取类）里读取，再转发给背包组件；背包组件本身不碰 Input System。
   - **不要**加鼠标点击、E 键或其他动作。
4. **地上的物品**：`WorldItem` 组件：持有一个 `ItemDefinition`，用占位小方块显示（约 0.4×0.4，颜色取自物品）；记录"多久后才能被捡"和"多久后消失"。
5. **自动捡起**：Player 半径 0.5 单位内的 `WorldItem`，在可捡状态下自动进背包（放不下就留在地上）。实现方式自定（Trigger 或距离检测都行），注意不要在 `Update` 里 `Find`。
6. **Q 丢弃**：从选中格减 1，在 Player 位置生成一个 `WorldItem`，2 秒内不可被捡，消失计时重新从 60 秒开始。
7. **界面**：
   - 背包栏用 uGUI（Canvas 屏幕空间）。**中文必须能正常显示**：请确认用的字体能显示"怪肉""蘑菇"（例如用 Unity 内置 LegacyRuntime 字体的 legacy `Text`，它会回退到系统字体；如果用 TextMeshPro，要处理中文字体和 TMP Essential Resources，别弹出需要用户点的导入窗口）。
   - 头顶图标：Player 子物体上的小色块（SpriteRenderer 即可）。
8. **场景生成器**：更新 `MMF/Build Prototype Scene`，在原有内容之外加上：
   - 背包栏 UI（含 EventSystem，如果需要）
   - 测试掉落物：**怪肉 4 个、蘑菇 4 个**，散放在 Player 周围、离 Player 至少 2 单位，不要放在墙里
   - 所有序列化引用（物品资源、UI、输入资源）都要在生成时连好。**生成后自己检查一遍关键引用不为空**，为空就 `Debug.LogError` 说明哪个空了。
9. **（可选，推荐）** 给 `BackpackModel` 写几个 EditMode 测试（`Assets/_MMF/Tests/`）：叠放顺序、满了放不下、丢 1 个、选格不循环。

## 验收标准

- [ ] 走到测试物品 0.5 单位内，物品自动消失并进入背包；同类先叠（最多 3 个），叠满再放下一个空格
- [ ] 背包放不下时，物品留在地上
- [ ] 1–5 键直接选格；滚轮下滚到下一格、上滚到上一格；两头不循环
- [ ] 头顶小色块显示选中格的物品；选中空格时不显示
- [ ] Q 在脚下丢 1 个；丢下后 2 秒内站在上面也不会捡回，2 秒后会捡回

- [ ] 所有 🟡 数值（格数 5、叠放 3、捡起距离 0.5、丢后 2 秒、消失 60 秒、头顶图标）都能在 Inspector 或数据资源里调
- [ ] 背包规则在纯 C# 类里，背包组件不引用 Input System

## 范围限制

- 不要做：E 键互动、料理站、食材箱、怪物、攻击、鼠标点击、餐车、顾客、金币、网络代码、正式美术。

## 给用户的试玩步骤
1. 回到 Unity，等编译完。
2. 菜单 `MMF → Build Prototype Scene`。
3. Play，点一下 Game 窗口：
   - 走向红色（怪肉）、米色（蘑菇）小方块 → 自动捡起，下方背包栏出现，同类叠在一起。
   - 按 1–5 或滚动滚轮切换格子，看高亮和头顶图标的变化。
   - 按 Q 丢 1 个在脚下，站着不动 2 秒后会自动捡回。
   - 测试物品放着 60 秒不捡会消失（要重新测，就重新运行菜单生成场景）。
