# T003 — 大地图 + 镜头跟随 + 占位餐车 + 进出餐车拉近拉远

> 给 Codex：先读 `AGENTS.md`，再读本说明书，再读 `docs/GDD.md` §5.2。T001、T002 已完成，先看懂 `Assets/_MMF/` 的现有结构。

## 目标
地图从"一屏"变成约 3 倍屏幕大，餐车占位在地图正中间（有墙，上下各一个车门）。镜头平滑跟着玩家走；玩家在车外时镜头拉远，进车后平滑拉近。玩家走不出地图，镜头也不会露出地图外面，玩家也不会走到背包栏下面被挡住。

## 规则（摘自 GDD，必须照做；🟡 = 以后会改，必须做成可调参数）

| 项目 | 值 |
|---|---|
| 地图大小 | **54 × 30** 单位，中心在原点 🟡 |
| 地图边界 | 玩家走到边界就停下，出不去 |
| 餐车 | **12 × 7** 单位（外框），在地图正中间 🟡 |
| 餐车墙 | 四面都有墙，玩家穿不过去 |
| 车门 | **上墙正中一个、下墙正中一个**，每个宽 **2** 单位 🟡 |
| "在车里"的判定 | Player 中心在餐车墙**内侧**的范围内 |
| 镜头（车外） | 能看到约 **25 × 14** 单位（正交尺寸 7） 🟡 |
| 镜头（车内） | 能看到约 **18 × 10** 单位（正交尺寸 5） 🟡 |
| 拉近 / 拉远 | **平滑**过渡；过渡时间做成参数，初始 **0.5 秒** 🟡 |
| 跟随 | **稍微延迟、平滑地跟上**玩家（例如 SmoothDamp），平滑时间做成参数，初始 **0.2 秒** 🟡 |
| 地图边缘的镜头 | 镜头**停住**，画面**不能露出地图外面**（任何缩放下都不行，包括缩放过渡中） |
| 背包栏 | 玩家**不能走到背包栏下面被挡住**（见下面"背包栏和地图下边"） |

### 背包栏和地图下边
镜头在地图下边停住时，地图最下面那一条会被背包栏盖住。处理方法：**玩家能走的范围，下边界往上抬高到背包栏的上沿**，也就是地图最下面那一条看得到（在背包栏后面），但玩家走不进去。
- 抬高多少，要按"车外镜头（正交尺寸 7）时，背包栏上沿对应的世界高度"算出来，再加一点可调余量。可以在运行时根据 `BackpackBar` 的 RectTransform 和镜头计算，也可以在编辑器生成时算好写进参数，自己选。
- 左、右、上三边不用抬高。

## 要做的事
1. **地图**：用一个组件（例如 `MapBounds`，`MMF.Core`）表示地图范围（54×30 可调），负责：铺地面、四面看不见的边界墙（下边按上面的规则抬高）。删除或替换 T001 的 `PrototypeArena`（它让场地贴合镜头，不再适用）。
2. **占位餐车**（`MMF.Truck`，例如 `TruckArea`）：
   - 车内地板（和车外地面颜色明显不同）、四面墙（深色，有 `BoxCollider2D`），上、下墙正中各留一个 2 单位宽的门洞。
   - 对外提供"某个位置是否在车里"的判断，以及玩家进 / 出车的事件或状态。
   - 尺寸、门宽、墙厚都是可调参数。墙厚自定（例如 0.5）。
3. **镜头**（`MMF.Core` 或 `MMF.Player`，例如 `FollowCamera`）：
   - 平滑跟随目标（Player）。
   - 根据玩家在车里 / 车外，平滑切换正交尺寸 5 / 7。
   - 每帧把镜头位置限制在地图范围内（按**当前**正交尺寸和画面宽高比计算），保证不露出地图外面。
   - 镜头逻辑在 `LateUpdate`；跟随 Rigidbody2D 插值后的位置，不要抖动。
4. **Player**：出生在餐车里正中间。移动、背包逻辑不改。
5. **测试物品**：T002 的 8 个测试物品（怪肉 4、蘑菇 4）改成**散放在餐车外的地图各处**（远近都有，有几个靠近地图边角），不要放在墙里或车里。
6. **场景生成器**：更新 `MMF/Build Prototype Scene` 生成以上全部内容。继续遵守 T002 补丁的做法：资源在 `NewScene` 之后加载，保存后重新打开场景再检查引用。

- [ ] 玩家只能从上、下两个门进出餐车，穿不过墙
- [ ] 走到地图四个边都会停下；镜头在边上停住，任何时候画面都不露出地图外面
- [ ] 走到地图最下边时，Player 停在背包栏上方，不被挡住
- [ ] 测试物品散在地图各处，捡起、选格、Q 丢弃都和 T002 一样正常
- [ ] 所有 🟡 数值都能在 Inspector 里调

## 范围限制
- 只新增 / 修改 `Assets/_MMF/` 下的文件。
- 不要做：料理站、食材箱、E 键互动、怪物、顾客、正式美术、网络代码。
- 不改背包规则和移动手感。
- 设计上有任何不清楚的地方，**不要自己决定**，写进回报的"疑问"。

## 给用户的试玩步骤
1. 菜单 `MMF → Build Prototype Scene`，Play，先点一下 Game 窗口。
2. 你在餐车里（浅色地板、深色墙），镜头比较近。
3. 从上门或下门走出去，镜头会慢慢拉远；走回车里会拉近。
4. 走到地图边上，看镜头会不会停住、会不会露出地图外面；走到最下边，看会不会被背包栏挡住。
5. 去地图各处捡测试物品。
