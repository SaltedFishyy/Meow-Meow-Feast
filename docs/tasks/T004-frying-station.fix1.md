# T004 补丁 1 — 审查发现的问题

> 给 Codex：先读 `AGENTS.md`，再读 `docs/tasks/T004-frying-station.md`（原任务）和 `docs/tasks/T004-frying-station.report.md`（你上次的回报），再读本补丁。T004 的代码已经在工作区里（还没提交），整体通过：编译、3 次生成、11 个测试、放入 / 煎制 / 超时焦土 / 退出 / 拿回 / "x" 都实测正常。下面是 Claude 在 Unity 里实测发现的问题，请修好。规则仍以 `docs/GDD.md` §5.5.1 为准。

## 1. 贴着锅台站时按不了 E / 左键（必须修）
- 现象：Player 是 1×1 的碰撞体，锅台也是 1×1。玩家贴着锅台站时，被物理推到离锅台中心 **1.01**（实测 x = -2.99，锅台在 -4），`InRange` 用的是**中心到中心**的距离 ≤ 1，结果返回 false。也就是说，玩家正常走过去，几乎永远够不着锅台。
- 修法：操作距离改成**玩家中心到锅台占地方块最近点**的距离 ≤ `_interactionDistance`（1 单位，🟡 可调）。可以用 `Collider2D.ClosestPoint`，或者自己按 1×1 方块算。举着时锅台的碰撞体是关的，要确保这时候的判断不会出错。

## 2. 锅台几乎放不下来（必须修）
- 现象：玩家在 (0,0)，朝右，目标格 (1,0)。`OverlapBoxAll(target, 1×1)` 检测到了 Player 自己的碰撞体（玩家右边 x=0.5，刚好和目标格左边接触），所以判定为重叠，放不下。玩家站在格子中心时，前方一格永远和玩家"接触"。
- 修法：重叠检测时把检测框稍微缩小一点（例如每边缩 0.05，做成常量或序列化字段），只把**真正的重叠**算作放不下，刚好贴边的不算。墙同理。

## 3. 格子没有对齐到餐车内部，锅台没法靠墙（必须修）
- 现象：餐车内部是 11 × 6（x 从 -5.5 到 5.5，y 从 -3 到 3）。按世界整数坐标对齐时，y 方向的格子是 1.5–2.5、2.5–3.5，**永远和上墙差 0.5**。x = -5 那一格刚好贴左墙，但 `TruckArea.Contains` 是严格小于，贴边会被判为"不在车里"。所以锅台**没法靠墙放**。初始位置 (-4, 2) 离左墙 1、离上墙 0.5，不是用户要的"左上角靠着上墙"。
- 修法：
  - 格子改成对齐**餐车内部**：从内部左下角开始，每格 1 单位。也就是 x 中心是 -5, -4, …, 5，y 中心是 -2.5, -1.5, …, 2.5。
  - "整个格子在车里"的判断允许刚好贴着内墙（加一点容差）。
  - 锅台初始放在车内**最左上角的那一格**（-5, 2.5），也就是贴着左墙和上墙，不挡上门。
  - 尽量让格子从 `TruckArea` 的数据算出来，不要写死坐标；改了车的大小也能用。

## 4. 煎的画面盖住了背包栏第 5 格
- 现象：截图里画面从屏幕最底下开始，盖住了背包栏最右边那格。
- 修法：画面的下沿放在**背包栏上沿的上方**（像 `MapBounds` 那样按背包栏 RectTransform 算），或者让背包栏显示在画面上层。选一个不会盖住背包栏的做法，写进回报。
