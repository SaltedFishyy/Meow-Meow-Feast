# T005a — 怪物"咒化团子"：朝餐车走、被打、死亡、重生

> 给 Codex：先读 `AGENTS.md`（尤其是 "Good structure, minimal changes" 和 "No dead code"），再读本说明书，再读 `docs/GDD.md` **§5.8.1**（只读"咒化团子"那部分，掉落不属于本任务）。
> 这是**小任务**，T005 怪物系统一共分三步：**a. 怪物本身（本任务）**；b. 平底锅武器（下一个任务，会调用本任务的"受伤"方法）；c. 掉落表（再下一个任务）。

## 目标
车外有 5 只紫色方块怪物"咒化团子"，直线朝餐车走，走到车边贴着停下，进不了车。它们能被打（本任务先用代码调用来测）：被打中时闪白一下、往后退一点；血量归零就消失，20 秒后在原来的出生点重新出现，再朝餐车走。

## 规则（🟡 = 必须做成可调参数）
| 项目 | 值 |
|---|---|
| 外观 | 紫色方块（占位），边长 **0.8** 🟡 |
| 血量 | **3** 🟡 |
| 移动 | 从当前位置**直线朝餐车中心**走，速度 **1.5** 🟡。被墙挡住就贴着墙停下（不要求绕路） |
| 碰撞 | 有碰撞体，玩家穿不过去；怪物之间也互相挡 |
| 餐车 | 怪物**进不了车**：上下两个门洞对怪物是挡住的，对玩家仍然能走 |
| 打玩家 | **不打**。贴着车也**不扣任何东西**（餐车血量以后做） |
| 出生点 | 车外固定 **5 个**，位置你定，要求：散在餐车四周，离车有一段距离（例如 6–10 单位），不在地图边缘或墙里，每个点 1 只 |
| 重生 | 死后 **20 秒** 🟡 在**原来的出生点**重生 |
| 被打中 | 闪白一下（时长 🟡，例如 0.1 秒），沿"攻击方向"往后推 **0.3** 单位 🟡 |
| 死亡 | 消失（这次不掉东西，掉落在 T005c 做） |

- 数值放进一个 ScriptableObject（例如 `MonsterDefinition`）。以后会有更多种怪物，同一套代码靠换数据资源就能用。
- 对外提供**一个**受伤方法，供 T005b 的武器调用，例如 `TakeHit(int damage, Vector2 direction)`。另外提供一个死亡事件（例如 `Died`），T005c 掉落会用到。这两项本任务就要用来测试，所以不算多余代码。
- "门挡怪物不挡玩家"：可以在门洞加只挡怪物的碰撞体，再用 `Physics2D.IgnoreCollision` 让玩家忽略它们，或者用其他不需要改 `ProjectSettings` 的办法。**不要改 Physics2D 的 Layer 设置**（那在 ProjectSettings 里）。

## 验收标准
- [ ] 编译无报错无警告；场景生成 3 次，引用都不为空；现有 27 个 EditMode 测试都通过
- [ ] Play：车外 5 只紫色方块，直线朝餐车走，走到车墙边停下；正对着门的那只也进不去
- [ ] 玩家仍然能从两个门进出；玩家撞到怪物会被挡住
- [ ] 用代码调用受伤方法：怪物闪白、往后退约 0.3；打 3 次（每次 1 点伤害）后消失；约 20 秒后在原来的出生点出现，又开始朝车走
- [ ] 所有 🟡 数值都在 Inspector 里可调（数据资源里）
- [ ] 建议加 EditMode 测试：血量扣减、死亡只触发一次、不会扣到负数

## 范围限制
- **不做**：武器、攻击输入、左键逻辑（T005b）；掉落、移除地图上的测试怪肉（T005c）；血条、餐车血量、怪物打玩家、寻路、波次。
- 不改移动、背包、煎锅台、镜头的任何行为。
- 设计上有不清楚的地方，写进回报的"疑问"，不要自己决定。

## 给用户的试玩步骤
1. 菜单 `MMF → Build Prototype Scene` → Play。
2. 走出车外，能看到 5 个紫色方块慢慢朝餐车走，最后贴在车墙外。
3. 这一步还不能打怪（平底锅在下一个任务），只看它们走、会不会进车、会不会挡住你。
