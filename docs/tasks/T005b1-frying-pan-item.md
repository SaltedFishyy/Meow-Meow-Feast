# T005b1 — 平底锅物品：开局在背包第 1 格，丢在地上不消失

> 给 Codex：先读 `AGENTS.md`（尤其是 "Good structure, minimal changes" 和 "No dead code"），再读本说明书，再读 `docs/GDD.md` §5.3.1。T005a、T005a2、T005a3 已完成并提交。
> 这是**小任务**，只做"平底锅这个物品"。**不做攻击**（T005b2）、**不做挥锅的扇形**（T005b3）、不做掉落表（T005c）。

## 目标
开局背包第 1 格里有一个"平底锅"（灰色色块 + 文字"平底锅"）。它和其他物品一样能用 Q 丢、能捡回来，但丢在地上**不会消失**。拿着它对锅台按 E 会显示"x"（不能煎）。

## 相关设计
- `docs/GDD.md` §5.3.1 武器：初始武器"平底锅"
- `docs/GDD.md` §5.2 背包、掉落物（已有的丢弃 / 捡起规则）

## 要做的事
1. **物品数据**：`ItemDefinition` 加一个序列化开关"丢在地上不会消失"（🟡【暂定】，默认关）。只有平底锅打开。
2. **开局物品**：`PlayerBackpack` 加一个序列化的"开局物品"列表。玩家出生时按顺序放进背包，所以第一个就在第 1 格。放的规则用已有的 `TryAdd`。
3. **丢在地上不消失**：`PlayerBackpack.DropItem` 生成掉落物时，如果物品打开了"不会消失"，寿命就设成无限（例如 `float.PositiveInfinity`）。其他规则（2 秒后才能捡回、捡起规则）和其他物品一样。**`WorldItem` 不用改**：确认它在寿命无限时能正常工作。
4. **生成器**：`PrototypeSceneBuilder` 生成物品资源 `Data/Items/FryingPan.asset`：id `FryingPan`，显示名"平底锅"，灰色（例如 (0.55, 0.55, 0.55)），没有煎的结果，"不会消失"打开。如果资源已经存在，也要确保这些字段是对的（现有的 `LoadItem` 只在资源不存在时才设置字段，注意这点）。把它放进玩家的开局物品列表。
5. **不能煎**：平底锅没有煎的结果，现有的锅台逻辑已经会显示"x"。**不用改锅台代码**，只要确认。

## 验收标准
- [ ] 编译无报错无警告；场景生成 3 次，引用都不为空；原有 76 个测试全部通过
- [ ] Play：背包第 1 格显示灰色色块 +"平底锅"，其他 4 格是空
- [ ] 选中第 1 格按 Q：平底锅掉在脚下，2 秒后走过去能捡回；放在地上超过 60 秒也不会消失
- [ ] 其他物品（怪肉、蘑菇）丢在地上还是 60 秒消失
- [ ] 拿着平底锅对锅台按 E：头上显示"x"，锅里没东西放进去
- [ ] 背包里有平底锅时捡东西，其他物品照常放进其他格子

## 给用户的试玩步骤

2. 看背包第 1 格：灰色"平底锅"。
3. 按 1 选中，按 Q 丢在地上，2 秒后走过去捡回来。丢下以后等 1 分钟以上，它还在。
4. 拿着平底锅走到锅台旁按 E：头上出现"x"。
