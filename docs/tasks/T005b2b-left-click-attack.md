# T005b2b — 左键接上平底锅攻击（朝鼠标方向，按左键优先级）

> 给 Codex：先读 `AGENTS.md`（尤其是 "Good structure, minimal changes"），再读本说明书，再读 `docs/GDD.md` §5.3.1 的"左键的优先级"。T005b2（`PlayerAttack.TryAttack`）已完成并提交。
> 这是**小任务**，只做"左键按下时，决定是搬锅台还是攻击"。不做扇形显示（T005b3）。

## 目标
玩家选中平底锅、在车外按鼠标左键，就会朝**鼠标所在的方向**挥一下，打到扇形里的怪。在锅台旁边或者举着锅台时，左键还是搬锅台。

## 左键优先级（GDD §5.3.1，按顺序判断，前面的成立就不往下走）
1. 煎菜画面打开时 → 什么都不做（不能打，也不搬）。
2. 举着锅台时 → 放下锅台（放不下也算用掉了这次左键，**不攻击**）。
3. 在锅台旁边（锅台已有的互动距离）→ 举起锅台。
4. 其他情况 → 攻击：`PlayerAttack.TryAttack(鼠标的世界坐标)`。选中的不是武器时，`TryAttack` 自己会返回 false，什么都不发生。

## 要做的事
1. `PlayerInteractor.Lift()` 改成返回 `bool`：上面第 1–3 种情况返回 true（表示"这次左键被锅台用掉了"，包括正在煎菜、放不下），第 4 种情况返回 false。**方法里原来的行为一点都不改**，只加返回值。
2. `PlayerInputReader` 的 "Lift" 动作：先调用 `_interactor.Lift()`；返回 false 时，再调用 `PlayerAttack.TryAttack(鼠标世界坐标)`。
   - 鼠标世界坐标：用 `Mouse.current.position` 读屏幕坐标，再用主摄像机转换成世界坐标。摄像机在 `Awake` 里取一次存起来，不要每次都 `Camera.main`。`Mouse.current` 为 null 时（没有鼠标）不攻击。
   - `PlayerAttack` 在 `Awake` 里用 `GetComponent` 取一次。
3. 不改 `MMFControls.inputactions`（左键已经绑定在 "Lift" 上）。

## 验收标准
- [ ] 编译无报错无警告；场景生成 3 次，引用都不为空；原有 87 个测试全部通过
- [ ] Play，选中平底锅，出车门到车外，鼠标放在怪物那边按左键：怪闪白、被打退、扣血；连按时每 0.4 秒最多打一次
- [ ] 鼠标在玩家左边就往左挥，在右边就往右挥（打不到背后的怪）
- [ ] 站在锅台旁边按左键：举起锅台，不攻击；举着锅台按左键：放下（放不下就没反应），不攻击
- [ ] 煎菜画面打开时按左键：什么都不发生
- [ ] 选中空格或其他物品按左键：什么都不发生
- [ ] 锅台的其他功能（E 放食物、WASD 煎、放置预览）不变

## 给用户的试玩步骤

2. 按 1 选中平底锅，从车门出去，走近一只紫色怪物。
