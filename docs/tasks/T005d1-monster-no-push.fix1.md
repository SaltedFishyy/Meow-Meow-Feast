## 还没通过的
**玩家往怪物身上走（按着方向键顶住怪物）时，玩家会被慢慢往后推，怪物跟着走。**

| 场景 | 结果 |
|---|---|
| 1 只怪在玩家右边 (1, −9)，玩家在 (0, −9) 一直按"右"，**怪物的 `Monster` 组件关掉**（`enabled = false`） | 2 秒后玩家在 (0.085, −9)，速度 0。**正常**：被挡住、停下 |
| 同样的位置，**`Monster` 组件打开** | 2 秒后玩家在 (−1.58, −9)，速度 (−0.40, 0)，怪在 (−0.67, −9)。**玩家往右按，却被推着往左走**，怪一直跟着 |
| 3 只怪三面围住，玩家按"下"（朝下面那只怪） | 玩家从 y = −9 被推到 −7.8，**和按的方向相反** |

所以问题还在 `Monster` 这边：玩家主动贴进怪物的安全间隙以后，怪物的移动还是会把玩家推开。可能的原因（请你自己确认）：
- `LimitDynamicContact` 只在**最后**限制移动，但前面的 `Cast` / 滑动 / 避让算出来的方向可能有分量朝向玩家。
- 或者玩家已经在间隙里时（`hit.distance <= 0`），法线方向判断有问题。
- 或者还有别的 `MovePosition` 路径没经过 `LimitDynamicContact`。

## 要修
- 玩家按着方向键顶住怪物时，**玩家停在原地**（速度约为 0，和关掉 `Monster` 组件时一样），**不会被往反方向推**，怪物也不会"跟着推"。
- 上面已经通过的情况不能改坏。
- 下一个任务 T005d2 会做"玩家能慢慢挤开怪物"，这里**还不要做**，现在只要求"顶住时双方都不动"。
