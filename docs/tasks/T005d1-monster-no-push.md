# T005d1 — 修卡死：怪物不能推玩家

> 给 Codex：先读 `AGENTS.md`（尤其是 "Good structure, minimal changes"），再读本说明书，再读 `docs/GDD.md` §5.8.1 开头新加的"怪物不推玩家"。T005a～T005c 已完成并提交。
> 这是**小任务**，只修"怪物把玩家推走"这个 bug。**"玩家能慢慢挤开怪物"是下一个小任务 T005d2**，这里不做。

## 问题（用户试玩发现，Claude 已复现）
用户：怪物靠近角色以后会把角色卡住，WASD 都用不了。

Claude 在 Play 里复现（玩家在车外，其他怪移到远处）：
1. **1 只怪**：玩家在 (0, −9) 不按键，怪从右边 (3, −9) 追过来。3 秒后玩家被推到了 (−1.35, −9)，怪在 (−0.43, −9)。也就是说，怪贴上玩家后**一直推着玩家往左走**。
2. **3 只怪**：从左 (−3, −9)、右 (3, −9)、下 (0, −12) 三面追过来。3 秒后玩家被推到 (0, −7.41)；之后玩家**按"下"**，还是被推着往上走（−7.41 → −5.47 → −3.48），一直顶到车底墙上，往左也走不动。这就是"卡死"。

物理设置：玩家是 Dynamic `Rigidbody2D`（`PlayerMovement` 设置速度）；怪物是 Kinematic，用 `Rigidbody2D.Cast` + `MovePosition` 移动，停在离障碍物 `ContactGap`（0.002）的位置。`Physics2D` 默认的 contact offset 是 0.01，比 `ContactGap` 大。Claude 猜可能和这个有关（Kinematic 物体进入 contact offset 范围后，物理引擎把 Dynamic 的玩家挤开），**但请你自己确认真正的原因**，并在回报里写清楚。

## 要做的
- 怪物走到贴着玩家时停下，**永远不会让玩家的位置因为怪物而改变**（玩家不按键时，被怪物贴着也纹丝不动）。
- 玩家仍然被怪物挡住，**不能穿过**怪物（往怪物身上走会停下）。这个任务里玩家还推不动怪物（T005d2 再做）。
- 怪物原有的行为都不变：追玩家 / 去车头车尾、沿墙滑、绕车角、互相避让、被打击退、门洞挡板。

## 结构要求
- 优先只改 `Monster` 的移动部分。如果非改 `PlayerMovement` 或 Physics2D 设置不可，**先别改**，在回报的"疑问"里说明为什么、打算怎么改，Claude 再决定。
- 不要每帧 `GetComponent` / 分配内存。
