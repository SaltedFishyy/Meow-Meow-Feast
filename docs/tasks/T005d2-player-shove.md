# T005d2 — 玩家能慢慢挤开怪物（推的时候速度减半）

> 给 Codex：先读 `AGENTS.md`（尤其是 "Good structure, minimal changes"），再读本说明书，再读 `docs/GDD.md` §5.8.1 开头的"怪物不推玩家""玩家能慢慢挤开怪物"。T005d1（怪物不再推玩家）已完成并提交。
> 这是**小任务**，只做"玩家往怪物身上走时把怪物推开"。

## 目标
现在玩家顶住怪物时，双方都停下（T005d1）。改成：玩家按方向键往怪物身上走时，**怪物被往同一个方向推开**，玩家跟着往前走，但速度只有平时的**一半** 🟡【暂定】。被围住时，玩家可以从怪物中间慢慢挤出去。

## 规则（GDD §5.8.1）
- 只有玩家**主动往怪物身上走**（移动方向朝着怪物）时才推。玩家不动或往别处走时，怪物照常行动，T005d1 的"怪物不推玩家"不变。
- 推的时候：玩家速度 = 平时 × **0.5** 🟡（做成序列化参数）；怪物沿玩家的移动方向被挪开，挪的速度和玩家推的速度一样，让玩家能跟着往前走。
- 怪物被推时**也会被墙、餐车、门洞挡板、其他怪物挡住**（用怪物现有的碰撞检测）。推不动时玩家也停下，不能穿过怪物。
- 被推的怪物**不扣血、不闪白**，只是被挪开。被推的那一帧怪物不自己追玩家（不要和推的方向打架）；松开以后马上恢复原来的行为。
- 同时顶着两只怪时，两只都推，速度还是一半（不叠加减速）。

## 要做的事
1. 新脚本 `PlayerShove`（MonoBehaviour，放在 Player 上）：
   - 每个物理帧，玩家有移动意图时，沿移动方向用玩家的刚体 / 碰撞体做一次短距离检测（复用数组，不分配内存）。找到挡在前面的怪物（`Monster`；`TryGetComponent` 只在真的碰到时调用），就让它被推开，并告诉 `PlayerMovement` 这一帧用一半速度。
   - 没有顶到怪物时，速度恢复正常。
   - 推的速度比例（默认 0.5）、检测距离做成序列化字段。
2. `Monster` 加一个公开方法，例如 `Shove(Vector2 displacement)`：本帧被推开这么多（走怪物现有的碰撞检测，被墙 / 车 / 其他怪挡住就推不动）。**不扣血、不闪白**，本帧不自己追。可以复用现有的击退通道（`_knockback`），但不要影响 `TakeHit` 的行为。
3. `PlayerMovement` 加一个设置速度比例的公开方法或属性（例如 `SetSpeedMultiplier(float)`，默认 1），`FixedUpdate` 里目标速度乘上它。其他逻辑不动（加速、减速、`SetBlocked`、`LastMoveDirection`）。
4. 生成器：给 Player 加 `PlayerShove`，引用都填好。
5. 执行顺序：确保"玩家决定推 → 怪物被挪开 → 玩家前进"在同一帧里的先后合理，不出现推一下停一下的明显卡顿。需要的话用 `[DefaultExecutionOrder]`，在回报里说明。

## 验收标准
- [ ] 编译无报错无警告；场景生成 3 次，引用都不为空；原有 93 个测试全部通过
- [ ] 1 只怪在玩家右边，玩家按"右" 2 秒：玩家往右走了大约 2 × 2.5 = 5 格（±1），怪一直在玩家前面被推着走，两者不重叠
- [ ] 怪被推到车墙上：推不动，玩家也停下，不会穿过怪物或把怪推进墙里
- [ ] 3 只怪三面围住，玩家朝其中一只按方向键：能慢慢挤出去
- [ ] 玩家不按键时，怪物还是不推玩家（T005d1 的行为不变）
- [ ] 被推的怪不扣血、不闪白；平底锅打怪、击退照常
- [ ] 没有顶到怪物时，玩家速度和原来一样（5）
- [ ] 玩家在车里时 5 只怪都到车头 / 车尾；车底迎面相撞的两只能错开（之前的行为不变）
