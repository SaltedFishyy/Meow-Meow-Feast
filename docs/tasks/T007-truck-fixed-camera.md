# T007 — 进了餐车镜头固定在车中间，出车再跟玩家

> 给 Codex：先读 `AGENTS.md`，再读本说明书和 `docs/GDD.md` §5.2（镜头与场地，2026-11-16 的改动）。
> 这是**小任务**：只改镜头的位置规则。镜头远近（拉近拉远）、地图边缘停住等现有行为都不变。

## 目标
- **车外**：和现在一样，镜头稍微延迟地跟着玩家。
- **车里**：镜头不跟玩家，固定在餐车上。玩家在车里走动，镜头一动不动。
- **固定位置**：餐车位于"背包栏上面那块画面"的正中间。也就是把镜头往**下**挪，让车在画面里往上一点，挪的距离 = 背包栏占画面的高度的一半（世界单位）。这样背包栏不挡住车的下边。
- **进出车的过渡**：
  - 进车：镜头从当前位置**平滑滑到**固定位置。用的时间和曲线跟现在的拉近完全一样（`CameraTuning.ZoomDuration`，`SmoothStep`），两者同时进行、同时结束。
  - 出车：镜头从固定位置平滑滑回"跟随玩家的位置"，同样和拉远同时进行、同时结束；之后照常跟随（`FollowTime` 延迟）。出车时玩家还在走，目标是移动的，滑动要平顺，不能跳一下。
  - 过渡没结束时又进 / 出车（来回进出门），也要从当前位置平滑开始新的过渡，不能跳。
- 开局玩家在车里：镜头直接在固定位置，不用滑。
- 地图边缘限制（`ApplyBounds`）照常作用。

## 要做的事
1. `MapBounds`：把 `RefreshLayout` 里已经算出来的"背包栏顶边占画面高度的比例"（`fraction`）提供成一个**只读公开属性**，例如 `BackpackScreenFraction`，给镜头用。`RefreshLayout` 的现有行为不变。
2. `FollowCamera`：按上面的规则改镜头位置。固定位置 = 餐车中心（`TruckArea` 的位置）往下挪 `当前镜头半高 × BackpackScreenFraction`。镜头半高用当前的 `orthographicSize`。
3. **不加新数值**：过渡时间就是现有的"拉近拉远时间"。如果你觉得必须加新数值，写进"疑问"，不要自己加。
