# T008b1 — 松开右键用力扔出去：地上滑、摩擦减速、撞墙反弹

> 给 Codex：先读 `AGENTS.md`（尤其是 "Tunable gameplay values (数值)"），再读本说明书和 `docs/GDD.md` §背包里的"**右键蓄力丢**"（2026-11-16 已改成"用力扔、有惯性"）。
> T008a 已完成并提交：`PlayerThrow`（蓄力规则，`Release` 现在只结束蓄力）、`ThrowArrow`（箭头）、`ThrowTuning`、右键输入都已经接好。
> 这是**小任务**：只做"松开右键 → 用一个出手速度把东西扔出去 → 在地上滑、越来越慢、撞墙反弹 → 停下变成普通掉落物"。
> **不做**：空中飞的那一段（影子、升高落下），那是下一个小任务 T008b2；打中怪物的效果以后再做。

## 目标
- **力 = 出手速度**：蓄力进度 0～1（按住时间 / 蓄满时间，最多 1）对应出手速度，从"没蓄力时的出手速度"到"蓄满时的出手速度"线性变化。
- **箭头长度表示力的大小**，不再表示落点：箭头长度 = 从"箭头最短"到"箭头最长"按蓄力进度变化。箭头最短 / 最长是外观，放在 `ThrowArrow` 的序列化字段上（默认 1 和 3），**不进数值文件**。
- 松开右键时，如果正在蓄力：
  - 选中格子里有东西 → 拿出 **1 个**（和 Q 一样从选中格子减 1），从角色中心沿 `PlayerThrow.Direction` 以出手速度出发。
  - 选中格子是空的（蓄力时换到了空格）→ 什么都不扔，只结束蓄力。
- **滑行**：在地上直线滑，速度每秒减少"地面摩擦（减速）"那么多（匀减速）；速度降到很小（技术常量，例如 0.05）就停下。
- **撞墙反弹**：碰到**餐车墙**（`TruckArea` 的 `_walls`）或**地图边缘墙**（`MapBounds` 的四面墙）时，像球撞墙一样**按墙面反射方向**弹回，速度乘以"撞墙后保留多少速度"，然后继续滑到停。物品不能穿墙、不能和墙重叠（按物品显示大小留出半个物品的距离）。一帧里移动距离大时也不能穿墙。
  - **不会**被这些挡住：怪物、玩家自己、锅台、`Monster Door Blocker`（车门上只挡怪物的隐形墙）、地上的其他物品。
  - 用什么方法检测和反弹你选（例如只对这些墙的碰撞体做形状投射，或者自己算和墙包围盒的交点和法线），回报里写清楚。不要给滑行物体加会推开玩家 / 怪物的物理碰撞。
- **还在滑的时候**不能被捡起。
- **停下以后**和 Q 丢的完全一样：变成普通掉落物（`WorldItem`），**从停下那一刻开始**算 2 秒才能被自动捡起、1 分钟消失；平底锅不消失（`NeverExpiresOnGround`）。复用 `PlayerBackpack.DropItem` 的建法（可以加一个"落在哪个位置"的参数或重载，Q 的行为不能变）。滑行中的样子和掉落物一样（颜色、大小、贴图）。
- 车里扔也可以：朝门扔能从门滑出去，朝墙扔会弹回来。

## 要做的事
1. **`ThrowTuning`**：
   - **删掉** `_minimumDistance`、`_maximumDistance`（和它们的属性），不再用"距离"。
   - 新加（都要 `TuningLabel` 中文名、`Min`）：
     | 字段 | 中文名 | 默认值 |
     |---|---|---|
     | `_minimumSpeed` | 没蓄力时的出手速度（格/秒） | 5 🟡 |
     | `_maximumSpeed` | 蓄满时的出手速度（格/秒） | 12 🟡 |
     | `_friction` | 地面摩擦（每秒减速多少格/秒） | 12 🟡 |
     | `_bounce` | 撞墙后保留多少速度（0～1） | 0.5 🟡（用 `Range(0, 1)`） |
   - `_chargeSeconds`（蓄满要几秒）保留。
   - 已经存在的 `ThrowTuning.asset` 里旧字段会自动作废、新字段用代码默认值，**不用生成器去改**。
2. **`PlayerThrow`**：
   - `Distance` 换成 `Charge`（蓄力进度 0～1）和 `LaunchSpeed`（当前出手速度）。`Release` 按上面的规则扔出去。
   - 需要的墙从 `TruckArea`、`MapBounds` 拿（给它们各加一个只读属性列出会挡住扔出物的墙，或在 `PlayerThrow` 上加序列化引用由生成器填，选最简单清楚的一种）。
3. **`ThrowArrow`**：长度改成按 `PlayerThrow.Charge` 在箭头最短 / 最长之间变化（新加两个序列化外观字段）。其他不变。
4. **新脚本 `Scripts/Player/ThrownItem.cs`**：只管滑行、撞墙反弹、停下时生成普通掉落物并删掉自己。摩擦、反弹每帧从 `ThrowTuning` 读（Play 中改马上生效）。
5. 生成器：只在需要时填新的引用。

- [ ] 滑行中走过去捡不起来；停下后 2 秒才能捡回；平底锅扔出去停下后不消失
- [ ] 蓄力时换到空格再松手：什么都不扔
- [ ] Q 丢东西和以前完全一样
- [ ] 数值窗口"丢东西"组是：蓄满要几秒、两个出手速度、地面摩擦、撞墙后保留多少速度；没有旧的"丢多远"；Play 中改摩擦 / 反弹马上生效

## 给用户的试玩步骤
1. Play，选中有东西的格子（例如平底锅），出车，按住右键蓄力，松开：东西被扔出去，越滑越慢，停下。

3. 停下 2 秒后走过去，自动捡回来。
