> 给 Codex：先读 `AGENTS.md`（尤其是 "Tunable gameplay values (数值)"），再读本说明书和 `docs/GDD.md` §背包里的"**右键蓄力丢**"。
> T008b1 已完成并提交：`ThrownItem` 现在出手就在地上滑（匀减速、撞墙反弹、停下变普通掉落物），`PlayerThrow.Charge` / `LaunchSpeed` 已有。
> 这是**小任务**：在"滑"前面加一段"空中飞"。打中怪物的效果以后再做，**这次不做**。

## 目标
- **空中时间**：出手时按蓄力进度 0～1，在"没蓄力时空中几秒"和"蓄满时空中几秒"之间线性取值（力越大飞越久）。默认 0 和 0.5 🟡。空中时间是 0 就直接进入滑行（和现在一样）。
- **空中这一段**：
  - 东西在地面上的位置（就是影子的位置）按出手速度直线前进，**空中没有摩擦，速度不变**。
  - **撞墙也反弹**：和滑行一样，碰到餐车墙 / 地图边缘墙就按反射方向弹回、速度乘以"撞墙后保留多少速度"，继续飞。怪物、锅台、玩家、车门上挡怪物的隐形墙照样不挡。
  - 空中时间到了 = 着地，着地后**保持当时的速度和方向**接着在地上滑（T008b1 的规则），直到停下变成普通掉落物。
- **样子**（俯视）：
  - 地上有一个**影子**跟着地面位置走：半透明深色，大小和物品差不多。影子只在空中这一段显示，着地后消失。
  - 东西本身画在影子**上方**，高度先升后降（抛物线，起点和终点高度都是 0，正中间最高）。**最高高度**和空中时间成正比：最高高度 = 空中时间 × 一个外观系数（默认 2，也就是飞 0.5 秒时最高 1 格）。这个系数、影子颜色 / 大小是外观，放在组件的序列化字段上，**不进数值文件**。
  - 东西在空中时画在影子上面、在地面物品上面（排序比地面物品高）。
- 空中、滑行中都不能被捡起；停下以后的规则不变。
