# T008c — 扔出去的东西撞到怪物会被挡住、弹开一点点

> 给 Codex：先读 `AGENTS.md`（尤其是 "Tunable gameplay values (数值)"），再读本说明书和 `docs/GDD.md` §背包"右键蓄力丢"（2026-11-17 改：撞到怪物会被挡住）。
> T008b1、T008b2 已完成并提交：`ThrownItem` 先匀速平移、再匀减速滑行，只和 `PlayerThrow._walls`（餐车墙 + 地图墙）做包围盒碰撞和反弹，停下变普通掉落物。
> 这是**小任务**：只让扔出去的东西也被**活着的怪物**挡住。

## 目标
- 扔出去的东西（平移段和滑行段都算）碰到**活着的怪物**（`Monster`，`gameObject` 是激活的）时：
  - 和撞墙一样：不能穿过、不能和怪物重叠（按物品半个大小留距离），**按碰撞面反射方向弹开**。
  - 弹开后速度乘以新数值"撞怪物后保留多少速度"（默认 **0.2** 🟡，比撞墙的 0.5 小，就是"弹一点点"），然后照常继续（还在平移段就继续平移，在滑行段就继续滑）。
  - **怪物没有任何反应**：不掉血、不后退、不闪、位置不变。不要调用怪物的受伤 / 击退方法，不要推动怪物。
- 怪物会动：每次检测用怪物**当时**的碰撞体位置。如果怪物走过来压到了正在移动的物品上（重叠），像墙一样把物品推出到怪物外面就行。
- 死了的怪物（`gameObject` 没激活）不挡。
- **不变**：锅台、玩家自己、车门上挡怪物的隐形墙、地上的物品仍然**穿过去**；墙的反弹仍用"撞墙后保留多少速度"；已经停下的掉落物不受怪物影响。
- 撞墙和撞怪物用**同一套**扫描 / 反弹代码，只是反弹系数不同，不要复制一份。

## 要做的事
1. `ThrowTuning`：加 `_monsterBounce`，中文名 `撞怪物后保留多少速度（0～1）`，默认 0.2，`Range(0, 1)`。
2. `ThrownItem`：把活着的怪物的碰撞体也算进障碍物，撞到时用 `_monsterBounce`。
3. 怎么拿到怪物：你选最简单清楚的方法（例如用 `Physics2D` 查询附近碰撞体再用 `GetComponentInParent<Monster>()` 过滤，像 `PlayerAttack` 那样；或者让 `MonsterSpawner` 提供一个只读的怪物列表）。注意不要每帧分配大量垃圾（查询用预先分配的数组 / 列表）。回报里写清楚用了哪种。
