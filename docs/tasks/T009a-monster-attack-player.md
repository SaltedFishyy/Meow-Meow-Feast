# T009a — 怪物"蹲一下再扑"打玩家 + 玩家血量（先只有扣血）

> 给 Codex：先读 `AGENTS.md`（尤其是 "Tunable gameplay values (数值)"），再读本说明书和 `docs/GDD.md` §5.3.2（玩家血量）、§5.8.1 里的"**攻击**"。
> 这是**小任务**：只做"怪物打玩家 → 玩家掉血"。
> **不做**（留给后面的小任务）：血量显示（T009b）、被打弹开 + 1 秒无敌 + 闪烁 + 穿怪（T009c）、血归零倒地 / 复活（T009d）、打餐车 + 餐车血量（T009e）、失败画面（T009f）、顾客。

## 目标
- **玩家血量**：开局满血 **5** 🟡。被打中一下掉"每下伤害"那么多（怪物定义里，默认 **1** 🟡）。最低到 0；到 0 以后这次**什么都不做**（倒地是 T009d），只是不再掉血、怪物也不再打他。
- **怪物攻击**（只打玩家；只在怪物正在**追玩家**时，也就是玩家在车外）：
  1. **发现**：怪物碰撞体边缘到玩家碰撞体边缘的距离 ≤ "攻击范围"（默认 **1** 🟡）、冷却已结束、玩家能被打（血 > 0）→ 进入**蹲**。
  2. **蹲**（"攻击前提示几秒"，默认 **0.5** 🟡）：怪物**停下不动**（不追、不避让），身上**闪烁提示**（例如在原色和一个提示色之间快速切换；提示色、闪的快慢是外观，放组件序列化字段，不进数值文件）。被玩家挤（`Shove`）、被打后退照常生效。
  3. **扑**：蹲完的那一刻，朝玩家**当时**的方向快速冲一小段（用怪物现有的、会被碰撞挡住的移动方式；碰到玩家、墙、别的怪物就停；冲的距离 = 攻击范围，冲多快 / 用几帧是外观，序列化字段）。**扑出去那一刻**判断：玩家还在攻击范围内、并且能被打 → 玩家掉血；已经躲出范围、进了车、或血是 0 → **扑空**，什么都不发生。
  4. **冷却**（"攻击冷却几秒"，默认 **1.5** 🟡）：冷却中照常追玩家，冷却完才能再蹲。
- 蹲的时候如果怪物被打死：攻击取消。怪物重生时攻击状态全部重置。
- 蹲的时候被平底锅打中：照常闪白、后退、掉血，攻击**继续**（不打断）。闪白和蹲的提示色冲突时你选一种清楚的处理，回报里写。
- 怪物不打在车里的玩家（隔着墙也不打）。

## 要做的事
1. **新数值文件 `Scripts/Data/PlayerHealthTuning.cs`**：`[TuningGroup("玩家血量", 9)]`，字段 `_maxHealth`（中文 `最多几格血`，默认 5，`Min(1)`）。以后弹开、无敌、倒地的数值也放这里（这次不加）。生成器用 `LoadPlayerHealthTuning()` 的写法：**只在缺失时创建**，不覆盖已有的。
2. **`MonsterDefinition`**：加 4 个字段（`TuningLabel` 中文名、`Min(0)`）：
   | 字段 | 中文名 | 默认值 |
   |---|---|---|
   | `_attackRange` | 攻击范围（边到边距离） | 1 |
   | `_attackWindUp` | 攻击前提示几秒 | 0.5 |
   | `_attackCooldown` | 攻击冷却几秒 | 1.5 |
   | `_attackDamage` | 每下伤害 | 1（int，`Min(0)`） |
3. **新脚本 `Scripts/Player/PlayerHealth.cs`**：只管血量。`Current`、`Max`、`CanBeHit`（现在 = 血 > 0）、`TakeHit(int damage, Vector2 direction)`（`direction` 这次不用，留给 T009c 弹开；如果你觉得现在不该留这个参数，回报里说）、事件 `Changed`（给 T009b 的显示用）。开局 / `OnEnable` 回满。
4. **新脚本 `Scripts/Combat/MonsterAttack.cs`**：只管"发现 → 蹲 → 扑 → 冷却"。找玩家用序列化引用（生成器填），判断玩家在车里用 `TruckArea`（像 `MonsterTargeting` 那样）。
5. **`Monster.cs`**：只加让攻击能用的最小接口，例如"蹲的时候不走"和"扑的位移"。**不要**把攻击逻辑写进 `Monster.cs`，不要改它现有的移动 / 避让 / 被打逻辑。
6. **生成器**：给玩家加 `PlayerHealth`，给每只怪物加 `MonsterAttack`，填好引用。已有的 `CursedDumpling.asset` 不覆盖（新字段会用代码默认值）。
