# T009b — 左上角显示玩家血量（5 个小方块）

> 给 Codex：先读 `AGENTS.md`，再读本说明书和 `docs/GDD.md` §5.3.2（玩家血量）。
> T009a 已完成并提交：`MMF.Player.PlayerHealth`（`Current`、`Max`、`Changed` 事件）。
> 这是**小任务**：只做血量显示。**不做**：弹开 / 无敌 / 闪烁（T009c）、倒地复活（T009d）、餐车血条（T009e）。

## 目标
- 屏幕**左上角**一排小方块，数量 = `PlayerHealth.Max`（默认 5）。
- 有血的格子是**亮色**（占位用红色），掉了的格子是**暗色**（深灰、半透明），所以一眼能看出还剩几格。以后会换成心形图片。
- 监听 `PlayerHealth.Changed` 刷新，不要每帧轮询。
- `Max` 变了（例如在数值窗口改了"最多几格血"后下次 Play）方块数量跟着变。
- 方块大小、间距、离屏幕边缘多远、两种颜色都是外观，放组件的序列化字段，**不进数值文件**。
- 用和背包栏同样的 uGUI 做法（`BackpackBar` 是参考）；可以放进背包栏已有的 Canvas，也可以新建一个，你选简单清楚的，回报里写。

## 要做的事

2. 生成器：建好左上角的锚点 / 容器，挂上组件，填 `PlayerHealth` 引用。
