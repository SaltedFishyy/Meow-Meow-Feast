# T009d2 — 倒地的样子：变灰、压扁躺着、头上倒计时 3、2、1

> 给 Codex：先读 `AGENTS.md`，再读本说明书和 `docs/GDD.md` §5.3.2"倒地细节"。
> T009d1 已完成并提交：`PlayerHealth`（`IsDown`、`Downed` / `Revived` 事件）、`PlayerDowned`（倒地计时、复活）。
> 这是**小任务**：只做倒地时的**样子**。规则不改。

## 目标
- 倒地的那一刻（`Downed`）：
  - 玩家方块**变灰**（占位灰色，外观字段）。
  - **压扁成躺着的样子**：例如显示用的缩放变成宽一点、矮一点（比例是外观字段，默认宽 1.2、高 0.5 左右，你定）。只改**显示**，不要改碰撞体大小。
  - 头上显示**倒计时**：剩 3 秒内显示"3"，然后"2"、"1"（向上取整剩余秒数）；倒地几秒在数值窗口改成别的值时也按剩余秒数显示。字要清楚（白字或带描边），位置在玩家头顶，跟着玩家（倒地被弹开时也跟着）。
  - 头顶原来的"选中物品小图标"倒地时隐藏，复活后恢复（如果做起来麻烦，回报说明，不要大改 `PlayerBackpack`）。
- 复活（`Revived`）：颜色、缩放完全恢复原样，倒计时消失；之后 T009c 的无敌闪烁照常（不要和闪烁的透明度互相覆盖：闪烁改的是透明度，变灰只改 RGB，恢复时也只恢复 RGB）。
- 倒计时需要的"还剩几秒"：给 `PlayerDowned` 加一个只读属性（例如 `RemainingSeconds`），不要在显示脚本里重复计时。
- 颜色、缩放比例、字号、倒计时位置都是外观，放组件序列化字段，**不进数值文件**。

## 要做的事
1. 新脚本 `Assets/_MMF/Scripts/Player/PlayerDownedView.cs`：只负责倒地的显示。
2. `PlayerDowned`：只加 `RemainingSeconds` 只读属性。
3. 生成器：加显示组件和倒计时用的物体（用世界空间的文字，例如 `TextMesh` 或世界空间 Canvas，你选简单清楚的，回报写明），填引用。

- [ ] 编译无报错无警告；场景生成 3 次，引用都不为空；93 个测试全部通过
- [ ] 被打到 0：方块变灰、变扁，头上依次显示 3、2、1
