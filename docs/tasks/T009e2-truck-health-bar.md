# T009e2 — 顶部中间的餐车血条 + "100/100"

## 目标
- 屏幕**顶部正中间**一条横的血条：
  - 底是深色（空的部分），上面是有颜色的填充（占位用绿色或红色，你选清楚的一种），填充长度 = `Current / Max`。
  - 血条上（或旁边）写 **"100/100"** 这样的文字（`Current/Max`），白字，清楚可读。
- 监听 `TruckHealth.Changed` 刷新，开局时显示满血（不要等第一次掉血才出现）。不要每帧轮询。
- 尺寸、颜色、字号、离顶部多远都是外观，放组件序列化字段，不进数值文件。
- 不能挡住左上角的玩家血量方块。

## 要做的事
1. 新脚本 `Assets/_MMF/Scripts/UI/TruckHealthBar.cs`：只负责显示车血。
2. 生成器：在已有的 Canvas 里建顶部中间的血条（锚在顶部中间），填 `TruckHealth` 引用。
