## 用户需要在 Unity 里做的事

1. 连续运行 `MMF → Build Prototype Scene` 三次，检查 Console，然后在 Test Runner 运行全部 93 项测试。
2. 进入 Play，先按 R 确认没有反应。留在车里等车血归零，确认失败提示、暂停和输入锁定，再按 R 检查开局状态。
3. 再做一轮失败和重开，并分别在倒地、煎锅计时和蓄力时验证暂停与重开。
