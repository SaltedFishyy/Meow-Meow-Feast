1. 连续运行三次 `MMF → Build Prototype Scene`，确认每次生成成功且引用完整。在 Test Runner 中运行全部 EditMode 测试。
2. 按 Play，捡地上的米色蘑菇，进车走到左上角锅台旁。从背包栏拖一个蘑菇进小锅，确认开始转进度环、来源格少 1 个、选中格不变。
3. 锅内有食物时再拖一个进去，确认显示 `x` 且背包数量不变。再把锅内食物拖回背包栏，确认锅空且无翻面动画。背包满时重复取回，确认显示 `x` 且锅内状态继续推进。
