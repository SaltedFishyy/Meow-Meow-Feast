# T014c2 — 新版煎锅 3b：鼠标划一下翻面、煎好进背包

> 给 Codex：先读 `AGENTS.md`，再读本说明书和 `docs/GDD.md` §5.5.1 **"新版"**那一段（"煎和翻面"、"鼠标左键"）。
> 已完成：T014a `MMF.Cooking.PanCooking`（`TryFlip(out cooked)`、`PutBackCooked`、事件 `Flipped`），T014b `MMF.UI.PanCookingView`（小锅画面、翻面动画），T014c1 `MMF.UI.PanDragInput`（背包栏 ↔ 小锅拖放、左键优先级）。
> 这是新版煎锅的最后一个功能小任务。旧版（E 键 + WASD）保持原样，删旧版是 T014d。

## 目标
- **划一下翻面**：小锅显示时，在**小锅画面上**按下左键（按在哪都行，不一定要按在食物上）→ 按住移动，**鼠标经过的路线碰到了食物** → 松开 → `PanCooking.TryFlip`。
  - "碰到食物"要按路线算：两帧之间鼠标跳得很远（划得快）、中间扫过了食物，也算。用屏幕坐标里"上一帧位置 → 这一帧位置"的线段和食物方块（屏幕上的矩形）是否相交来判断，按下那一点也算。
  - 要真的"划"：从按下到松开，鼠标至少移动"最短划动距离"（组件序列化字段，单位是小锅画面宽度的比例，默认 **0.15**；这是操作手感的界面参数，不进数值文件）。原地点一下不算翻。
  - 哪个方向都行；松开的位置可以在小锅外面，**但松开在背包栏格子上时按拖回处理**（见下）。
  - 还没到可以翻（煎不够 3 秒）、空锅、焦土、`Holding` 时划 → **什么都不发生**（不显示"x"）。
- **第 2 次翻 = 煎好**：`TryFlip` 给出煎好的物品 → 按正常捡东西的规则进背包（`PlayerBackpack.TryAdd`）；放不下 → `PanCooking.PutBackCooked` 把它留在锅里，显示"x"（`PlayerBackpack.ShowFailure()`），之后玩家可以拖回背包（T014c1 已支持）。
- **和"拖回背包"分清楚**（T014c1 已有：按在食物上 → 拖到背包栏松开 = 拿回）：
  - 按在食物上开始的一次按住：**松开在背包栏格子上 = 拖回**（和现在一样）；**松开在别处 = 按上面的划动规则判断是否翻面**。
  - 跟着鼠标的半透明图标：只在**鼠标离开小锅画面以后**才显示（在锅里划的时候不显示，免得看起来像在拖走）；回到小锅里又隐藏。从背包栏拖进锅的图标照旧一直显示。
- 左键优先级、倒地 / 输入关掉时取消，和 T014c1 一样（按在小锅上的左键不举锅台、不攻击）。

## 结构
- 修改 `Assets/_MMF/Scripts/UI/PanDragInput.cs`：在现有的按下 / 跟踪 / 松开流程里加划动路线记录和松开时的翻面判断。如果"线段和矩形相交"之类的计算想单独放，可以新增一个纯 C# 小工具类（例如 `Assets/_MMF/Scripts/UI/SwipeHit.cs`），并给它加 EditMode 测试；不新增就不用写测试。
- `LateUpdate` 里不要分配垃圾（不要每帧 new 数组 / List；食物的屏幕矩形可以每帧用复用的 `Vector3[4]` 算）。
- 不改 `PanCooking` / `PanCookingModel` 的规则，不改 `PanCookingView`（翻面动画已经听 `Flipped` 事件）。

## 给用户的试玩步骤
1. Play，捡蘑菇，进车走到锅台旁边，把蘑菇从背包栏拖进小锅。
2. 等进度环转满、食物闪"翻！"，在小锅上按住左键划过蘑菇再松开：翻面。
3. 再等 3 秒，再划一下：煎蘑菇进背包。
4. 不翻的话，最后 2 秒冒烟闪红，然后变焦土，拖回背包拿走。
