# T015 —【试验】锅的画面改到屏幕右边（数值窗口可开关）

> 给 Codex：先读 `AGENTS.md`，再读本说明书。这是用户要的**试验**，**不写进 GDD**（用户试完说通过才写）。
> 现在的新版煎锅：`MMF.UI.PanCookingView`（锅台头顶的世界空间小锅 + 进度环 / "翻！" / 快焦闪红冒烟 / 翻面动画）、`MMF.UI.PanDragInput`（背包栏 ↔ 锅拖放、在锅上划过食物翻面、左键优先级）、规则在 `MMF.Cooking.PanCooking`。

## 目标
- 新开关 `CookingTuning._panViewOnRight`，中文名 **"锅画面在右边（试验）"**，默认 **true**，出现在数值窗口"煎锅"组。**Play 中切换立刻生效**。
- **开关打开**：玩家靠近锅台（和现在同一个条件：在互动距离内，或者正举着锅台）时，**屏幕最右边**出现一个窗口：
  - 宽度 = 屏幕宽度的 **1/3**，**从上到下**占满高度（和以前旧版煎菜画面的位置、大小一样）；深色背景；**锅在窗口正中间**，里面的食物、进度环、"翻！"、烟、翻面动画、快焦闪红都和头顶小锅**一模一样**（只是放大到适合这个窗口，锅大约 280×280 像素参考分辨率）。
  - 这是普通的屏幕界面，**不是二级窗口**：玩家照样能用 WASD 走、捡东西、选格子；走远了窗口自动收起，锅里照样在煎。
  - 头顶的小锅**不显示**。
- **开关关掉**：和现在完全一样（锅台头顶的小锅），右边窗口不显示。
- **鼠标**（两种模式都一样）：
  - 从背包栏拖到**锅的画面**上松开 = 放进锅；在锅里按住食物拖到背包栏松开 = 拿回；在锅的画面上按住划过食物松开 = 翻面（最短划动距离按**锅**的宽度算，和现在一样）。
  - 右边模式下，**整个右边窗口**都算"锅的画面"：鼠标在窗口里按左键，不举锅台、不攻击。
- 原来所有规则、数值、提示都不变。

## 结构
- 显示逻辑和拖放逻辑**不要复制一份**：让 `PanCookingView` / `PanDragInput` 能用在"世界空间头顶小锅"和"屏幕右边窗口"两套画面上（例如场景里两套 UI 元素，各一个 `PanCookingView` 实例，加一个"模式"字段决定它在哪个开关状态下显示、要不要做头顶跟随和挪进画面；`PanDragInput` 对当前显示的那套画面做判断）。具体怎么接你定，回报说明。
- 屏幕空间 Canvas 判断鼠标时镜头传 `null`；世界空间照旧传主镜头。
- 最多新增 1 个脚本（如果需要），优先改现有的两个。
- 生成器：建右边窗口（在背包栏那个 Canvas 上或单独一个 Screen Space Overlay Canvas，排在背包栏下面一层，不挡背包栏和拖动图标）、填引用。已有的 `CookingTuning.asset` 不覆盖。

1. Play，捡蘑菇，进车走到锅台旁边：屏幕右边 1/3 出现锅的窗口，用 WASD 照样能走。
